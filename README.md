# Java: Consumindo API, gravando arquivos e lidando com erros ☕

Repositório com exercícios e desafios desenvolvidos durante o curso **"Java: Consumindo API, gravando arquivos e lidando com erros"** da Alura.

## 📖 Conteúdos estudados

- Consumo de APIs REST com Java
- Classe `HttpClient`
- Classe `HttpRequest`
- Classe `HttpResponse`
- Construção de URLs dinâmicas
- Codificação de parâmetros com `URLEncoder`
- Manipulação de respostas JSON
- Biblioteca Gson
- Conversão de JSON para objetos Java
- Records (`record`)
- Variáveis de ambiente para chaves de API
- Tratamento de exceções
- Exceções personalizadas
- Blocos `try-catch`
- Escrita de arquivos com `FileWriter`
- Geração de arquivos `.txt`
- Geração de arquivos `.json`
- Serialização de objetos com Gson
- Coleções com `ArrayList`

## 🛠️ Tecnologias utilizadas

- Java 26
- IntelliJ IDEA
- Git
- GitHub
- Gson
- OMDb API

## 📂 Funcionalidades desenvolvidas

- Busca de filmes através da API OMDb
- Conversão de respostas JSON para objetos Java
- Armazenamento de dados em objetos da aplicação
- Tratamento de erros de conversão de dados
- Criação de exceções customizadas
- Persistência de dados em arquivos `.txt`
- Exportação de listas para arquivos `.json`
- Busca contínua de filmes via terminal
- Uso seguro de chaves de API através de variáveis de ambiente

## 🎯 Objetivo

Praticar o consumo de APIs externas em Java, trabalhando com requisições HTTP, manipulação de JSON, tratamento de exceções e gravação de arquivos para armazenar informações obtidas de serviços web.
